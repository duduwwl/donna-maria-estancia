# Landing page — references

The Donna Maria layout uses the store's existing photographs and branding. The category navigation remains separate from the product catalog.

Public layout and animation references consulted on 27 September 2026:

- Codrops — Layer Motion Slideshow: https://tympanus.net/codrops/2019/01/24/layer-motion-slideshow/
- Codrops — On-Scroll Perspective Grid Animations: https://tympanus.net/codrops/2023/08/03/on-scroll-perspective-grid-animations/
- Motion — scroll animation examples: https://motion.dev/docs/react-scroll-animations

The responsive layout, image reveals, carousel and interactions are implemented locally in HTML/CSS/JavaScript. No paid template or third-party photographs were copied. The animation includes keyboard controls, touch navigation and reduced-motion support.
